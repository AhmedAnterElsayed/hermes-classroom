# hermes-classroom

🧠 Hermes Classroom Engine

An AI-powered educational system that teaches fractions through step-by-step digit construction, guided learning, and interactive quizzes.

🚀 Overview

Hermes Classroom Engine is a lightweight AI-inspired tutoring system designed to help students (especially beginners) understand fractions in a clear, visual, and structured way.

Instead of giving direct answers, it builds understanding through:

Long division steps
Digit-by-digit decimal construction
Percentage conversion
Instant quiz evaluation
Student performance tracking
🎯 Key Features
📊 Learning Engine
Converts fractions into decimals step-by-step
Shows long division process clearly
Builds final answer from digit “harvesting”
Converts result into percentage automatically
❓ Quiz System
Instant answer checking
Percentage-based evaluation
Score tracking
Streak system for motivation
👤 Student Dashboard
Student profile view
Attempt history tracking
Score and progress monitoring
Leaderboard support
🏁 Leaderboard System
Compares students by score
Tracks attempts and streaks
Encourages competition and engagement
🧠 Core Idea

Instead of simply outputting answers, Hermes focuses on:

Learning through structured reasoning, repetition, and visual step construction.

It simulates a teacher-guided learning loop:

Explain
Break down steps
Build answer progressively
Test understanding
Track performance
